# linkhub — бот-собеседник для чатов

Бот сидит в группах как обычный участник: болтает, помнит переписку и людей, здоровается с новичками,
играет в «пару дня» и рассылает рекламу с кнопками. Всё настраивается в личке с ботом командой **/admin**.

Старый бот-каталог лежит в ветке `old-linkhub`.

## Как бот решает, отвечать или нет

| Ситуация | Что делает |
|---|---|
| К нему обратились по имени (в любом падеже: Марат, Марату, Маратик), тегнули @username или ответили на его сообщение | Всегда отвечает через нейросеть, с учётом последних 20 сообщений чата |
| Люди общаются между собой | С шансом **4%** влезает в разговор (не чаще раза в 90 сек). Из этого **30%** через нейросеть, по теме, остальное случайная фраза, стикер или гифка из базы. Фразой может тегнуть кого-нибудь из чата |
| Кто-то вступил в чат | Здоровается по-своему, каждый раз новым текстом |
| Кончился дневной лимит денег на ИИ | До полуночи отвечает фразами из базы |
| Один человек долбит бота обращениями | Больше 5 раз в минуту молча пропускает, чтобы не жечь баланс |

Все проценты и паузы меняются для каждого чата отдельно в /admin.

## Что настраивается в /admin

| Раздел | Что можно |
|---|---|
| 💬 Чаты | для каждого чата: имя бота, доп. имена, характер, тема чата, шанс влезть, доля ИИ, пауза, приветствия, игры, реклама вкл/выкл, стереть память |
| 📣 Реклама | пост (текст, фото, видео, гифка, премиум-эмодзи) + кнопки-ссылки рядами, интервал от 30 мин до суток, пауза, удалять прошлый пост, предпросмотр, отправить сейчас |
| 🗯 Фразы и стикеры | база случайных реплик: присылаешь текст (строка = фраза), стикеры, гифки; просмотр и удаление |
| 📊 Расход | сколько потрачено на ИИ по дням и лимит |

## Память

* **Контекст переписки:** нейросеть видит последние 20 сообщений чата: кто что написал и кому отвечал.
  Фото, стикеры и голосовые она видит как пометки «[фото]», «[стикер 😂]».
* **Заметки о людях:** раз в 25 сообщений человека нейросеть перечитывает, что он писал, и обновляет
  короткую карточку: как зовут, откуда, чем увлекается. Бот учитывает её в ответах.

## Игры

`пара дня` · `шип` (ответом на сообщение) · `кто сегодня красавчик` · `предсказание` · `/games`

Рандомы берутся из тех, кто писал при боте: Telegram не даёт боту список всех участников.

## Установка на сервер (Ubuntu 24.04, systemd)

1. В @BotFather: создай бота, затем **Bot Settings → Group Privacy → Turn off**. Без этого бот не видит
   обычные сообщения в группах.
2. Заведи ключ на [platform.deepseek.com](https://platform.deepseek.com) и пополни баланс на $5.
3. На сервере от root:

```bash
apt update && apt install -y git
git clone https://github.com/dalmatinec/linkhub /opt/linkhub
bash /opt/linkhub/deploy/install.sh
```

Скрипт спросит токен, твой Telegram ID и ключ DeepSeek, поставит всё и запустит бота как сервис.

4. Напиши боту в личку /admin, добавь его в группу, в /admin → Чаты задай имя, характер и тему чата.

### Управление

```bash
journalctl -u linkhub -f          # логи
systemctl restart linkhub         # перезапуск
nano /opt/linkhub/.env            # настройки (лимит трат, модель), потом перезапуск
bash /opt/linkhub/deploy/update.sh  # обновиться с GitHub
```

База лежит в `/opt/linkhub/data/bot.db`. Чтобы сделать бэкап, достаточно скопировать этот файл.

## Другая нейросеть

Подходит любой сервис с API как у OpenAI. В `.env` меняются три строки, например OpenRouter:

```
AI_BASE_URL=https://openrouter.ai/api/v1
AI_API_KEY=sk-or-...
AI_MODEL=имя/модели
```

Не забудь поправить `PRICE_IN` и `PRICE_OUT` под цены модели, иначе расход посчитается неверно.

## Для разработки

```
bot/
  __main__.py        запуск, подключение роутеров и планировщика
  config.py          настройки из .env
  db.py              SQLite: чаты, юзеры, история, фразы, реклама, расход
  ai.py              запросы к нейросети и дневной лимит
  prompts.py         тексты запросов к нейросети (характер, стиль, задачи)
  brain.py           когда отвечать и чем
  games.py           логика игр
  textutil.py        разбор кнопок, упоминания
  middlewares.py     запись каждого сообщения группы в историю
  phrases_seed.py    стартовые фразы
  services/          talk (как бот говорит), memory (заметки о людях), ads (реклама)
  handlers/          group, games, members, private, admin/
deploy/              systemd-сервис, установка, обновление
tests/               python -m pytest -q
```
