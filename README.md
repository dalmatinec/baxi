# linkhub: бот-собеседник для чатов

Бот сидит в группах как обычный участник: болтает, помнит переписку и людей, здоровается с новичками,
играет в «пару дня» и рассылает рекламу с кнопками. Всё настраивается в личке с ботом командой **/admin**.

Старый бот-каталог лежит в ветке `old-linkhub`.

## Как бот решает, отвечать или нет

| Ситуация | Что делает |
|---|---|
| К нему обратились по имени (в любом падеже: Марат, Марату, Маратик), тегнули @username или ответили на его сообщение | Всегда отвечает через нейросеть, с учётом последних 20 сообщений чата |
| Люди общаются между собой | С шансом **4%** влезает в разговор (не чаще раза в 90 сек). Из этого **30%** через нейросеть, по теме, остальное случайная фраза, стикер или гифка из базы. Фразой может тегнуть кого-нибудь из чата |
| Кто-то вступил в чат | Здоровается по-своему, каждый раз новым текстом |
| Кончился дневной лимит денег на ИИ | До полуночи отвечает фразами из базы |
| Один человек долбит бота обращениями | Больше 5 раз в минуту молча пропускает, чтобы не жечь баланс |

Все проценты и паузы меняются для каждого чата отдельно в /admin.

## Что настраивается в /admin

Главная показывает сводку: чаты, заявки, заказы на проверке, звёзды и расход ИИ за сегодня.

| Раздел | Что можно |
|---|---|
| ⏳ Заявки | чаты, куда добавили бота без тебя |
| 📣 Реклама | заказы, форматы и цены, рассылка, свои посты по расписанию, настройки оплаты |
| ⭐ Монетизация | товары и цены, платежи и возвраты, топ донатеров, аренды |
| 🎨 Оформление | экраны лички, фразы и стикеры |
| 🤖 ИИ | расход по дням и модель |
| 💬 Чаты | карточка чата по разделам: 🎭 личность (имя, характер, тема), ⚙️ поведение (шанс, ИИ, пауза, час итогов), 🎲 фишки (приветствия, игры, реклама, как вам пара, итоги, репутация, ДР, магазин), 📅 доступ и аренда; стереть память, выйти |
| 📣 Реклама | пост (текст, фото, видео, гифка, премиум-эмодзи) + кнопки-ссылки рядами, интервал от 30 мин до суток, пауза, удалять прошлый пост, предпросмотр, отправить сейчас |
| 🗯 Фразы и стикеры | база случайных реплик: присылаешь текст (строка = фраза), стикеры, гифки; просмотр и удаление |
| 📊 Расход | сколько потрачено на ИИ по дням и лимит |

## Память

* **Контекст переписки:** нейросеть видит последние 20 сообщений чата: кто что написал и кому отвечал.
  Фото, стикеры и голосовые она видит как пометки «[фото]», «[стикер 😂]».
* **Заметки о людях:** раз в 25 сообщений человека нейросеть перечитывает, что он писал, и обновляет
  короткую карточку: как зовут, откуда, чем увлекается. Бот учитывает её в ответах.

## Фишки

**По обращению к боту по имени** (через ИИ):

| Просьба | Что делает |
|---|---|
| что тут было (за 3 часа, за день) | **только админы:** выжимка: болтун, самый смешной, матершинник с % мата, самый грубый и коротко о чём говорили. По умолчанию за час, максимум сутки |
| расскажи шутку | короткая шутка с чёрным юмором |
| прожарь его (ответом на сообщение, с @ или по имени) | дружеская прожарка по заметкам о человеке и его сообщениям |
| давай викторину | 5 вопросов по теме чата из /admin, кнопки с вариантами, кто первый правильно, +10 очков |

**Сам по расписанию:**

* **Как вам пара?** Днём (13:00-21:00), когда чат живой, раз в день кидает пару тех, кто больше всех отвечал
  друг другу, с кнопками 💘 / 🙅. Через час подводит итог.
* **Итоги дня** в 23:00 (меняется в /admin): болтун, пара дня, самый смешной, матершинник, самый грубый,
  сообщение дня с больше всего реакциями и шутка про день. Если за день меньше 20 сообщений, молчит.
* **Дни рождения:** в 10:00 поздравляет тех, у кого сегодня ДР.

**Команды в чате без обращения:**

| Команда | Кто может | Что делает |
|---|---|---|
| `итоги` | любой, раз в час на чат; админы без ограничений | итоги дня прямо сейчас |
| `сводка` (можно `сводка за 3 часа`) | только админы | то же, что «что тут было» |
| `пара` | только админы | сразу запускает голосование «как вам пара?» |
| `настройки` | только админы | кнопка в личку бота, где админ чата настраивает бота у себя |

Админ здесь: админ или создатель чата в Telegram, анонимный админ и владельцы бота из `OWNER_IDS`.

**Остальные команды, для всех:**

`пара дня` · `шип` (ответом) · `кто сегодня красавчик` · `предсказание` · `викторина` · `топ репы` ·
`топ викторины` · `репа` · `дни рождения` · `мой др 12.05` · `/games`

**Репутация:** `+`, `спасибо`, `спс` ответом на сообщение дают +1, `-` даёт -1. Одному человеку не чаще
раза в час, всего не больше 30 в сутки.

**Как считаются номинации.** Болтун и процент мата считаются кодом по словарю, бесплатно. Самый смешной:
реакции на его сообщения плюс ответы «ахах», «ору», «😂» на них. **Реакции бот видит, только если он админ
в чате.** Самого грубого и пересказ определяет ИИ.

Бот никогда не пишет длинное тире и кавычки-ёлочки: всё, что он отправляет в чат, чистится перед отправкой.
Рандомы берутся из тех, кто писал при боте: Telegram не даёт боту список всех участников.

## Чаты: одобрение и аренда

**Аренда с оплатой криптой:** человек в личке бота → Добавить в чат → добавляет бота в свою группу →
💳 Оплатить аренду → выбирает чат (только где он админ) → платит USDT. После оплаты бот сам включается в этом
чате на 30 дней, повторная оплата продлевает ещё на 30. **Свой бот** оплачивается так же (💳 Оплатить
криптой), тебе приходит «Оплачен свой бот» с кнопкой написать заказчику. Цены аренды и своего бота:
`/admin` → Реклама → Форматы и цены, на экранах цена подставляется сама.

Все объявления в чате (пришёл, представился после одобрения, напоминание о конце аренды, прощание) бот
пишет в образе своего персонажа через ИИ. Без ИИ берёт готовые фразы.

* Добавил бота **ты** (ID из `OWNER_IDS`): работает сразу.
* Добавил **кто-то другой**: бот в своём образе здоровается, говорит, что пока осматривается, и молчит. Тебе приходит
  заявка с кнопками **✅ Разрешить / 📅 Аренда 30 дней / 🚫 Выйти**. Нет ответа за сутки: бот сам выходит.
* **Аренда:** за 3 дня до конца бот предупреждает чат и тебя, в конце срока выходит. Продлить или сделать без
  срока: `/admin` → Чаты → чат.
* Если бота выгнали и добавили снова, нужно одобрить заново.

### Админы чатов настраивают бота сами

Когда чат одобрен, тот, кто добавил бота, получает в личку сообщение с кнопкой «⚙️ Настроить бота».
В главном меню лички у админов появляется кнопка **⚙️ Мои чаты** (видны только чаты, где человек админ или
создатель и где бот одобрен). В чате это же открывает команда `настройки`.

Админ чата может: имя и доп. имена, характер, тему чата, шанс влезть в разговор, долю ИИ, паузу, час итогов,
включать и выключать фишки (приветствия, игры, как вам пара, итоги, репутация, ДР, магазин), стереть память.
Только у владельца: реклама, фразы и стикеры, экраны и тексты лички, расход на ИИ, деньги, аренда.

## Личка бота для людей

`/start` открывает меню: Что я умею, Добавить в чат, Реклама, Магазин, Топ донатеров, Свой бот, Поддержка.
**Все экраны меняются без кода:** `/admin` → 🎨 Экраны и тексты. Там текст (с форматированием и
премиум-эмодзи), картинка, кнопки: название, цвет (синяя, зелёная, красная), премиум-эмодзи на кнопке, куда
ведёт, ряд, добавить и удалить.

Премиум-эмодзи в сообщениях и на кнопках бот показывает, **только если у владельца бота есть Telegram Premium**
(так устроен Telegram).

**Поддержка:** человек пишет сообщение, оно приходит тебе с кнопкой «Ответить», твой ответ уходит ему.

## Продажа рекламы

1. Человек в личке: Реклама → формат (видит охват: чаты, участники, люди в личке) → присылает пост и кнопки →
   видит предпросмотр → отправляет на проверку.
2. Тебе приходит пост и кнопки **✅ Одобрить / ❌ Отклонить / 💵 Оплачено напрямую**.
3. После одобрения заказчик получает точную сумму в USDT (например `10.0023`) и адреса. Бот раз в 30 секунд
   смотрит входящие переводы (toncenter для TON, TronGrid для TRC20) и сам находит платёж по сумме
   или по комментарию `AD<номер>`.
4. После оплаты бот публикует пост по формату и пишет заказчику итог.

Форматы: пост во все группы (можно на несколько дней), закреп в группах на сутки, закреп в канале на сутки,
рассылка в личку бота. Цены, названия и дни: `/admin` → 🛍 Форматы и цены. Заказы: `/admin` → 🧾 Заказы рекламы.
Своя рассылка без оплаты: `/admin` → 📢 Рассылка (в личку, по группам или везде).

Кнопки в постах: `Текст - ссылка`, ряды с новой строки, в ряду через `|`, цвет третьим: `- зелёная`,
`- синяя`, `- красная`.

### Как настроить приём USDT

Можно одну сеть или обе. Заказчик видит оба адреса и одну точную сумму, бот засчитает перевод в любой сети.

* **TON** (комиссия копейки): адрес Tonkeeper в сети TON, начинается на `UQ`/`EQ`, в `PAY_TON_ADDRESS`.
  Ключ toncenter (по желанию) у бота **@tonapibot**, в `TONCENTER_API_KEY`.
* **TRON / TRC20** (так часто платят с бирж): адрес USDT TRON, начинается на `T`, в `PAY_TRON_ADDRESS`.
  Ключ TronGrid (по желанию) на trongrid.io, в `TRONGRID_API_KEY`.

На сервере: `nano /opt/linkhub/.env`, вписать, сохранить (Ctrl+O, Enter, Ctrl+X), `systemctl restart linkhub`.

Если адрес не указан, заказчики после одобрения пишут в поддержку, а ты жмёшь «Оплачено напрямую».

## Магазин за звёзды

**В чате** по команде `магазин`. Для мута, пары, закрепа и прожарки нужно написать `магазин` ответом на
сообщение нужного человека:

| Товар | Что даёт | Цена по умолчанию |
|---|---|---|
| 🏷 Должность | настоящая подпись у имени в чате на 30 дней | 100 ⭐ |
| 🔇 Мут | человек 15 минут не может писать (админов и тех, у кого щит, нельзя) | 25 ⭐ |
| 📌 Закреп | сообщение в закрепе 2 часа | 30 ⭐ |
| 💘 Пара дня | ты и выбранный человек становитесь парой дня | 20 ⭐ |
| 🔥 Прожарка по полной | жёсткая прожарка в чате | 30 ⭐ |

**В личке**: 👑 VIP на 30 дней, 🛡 щит на 7 дней (не замутить и не прожарить), 💛 поддержать бота
20/50/100/500 ⭐.

**VIP** сам выбирает в личке (Магазин → Мой VIP) свой **премиум-эмодзи** и **ник**. Везде, где бот его
упоминает (топы, репутация, итоги, игры, пары, викторины, приветствия), он выглядит так: эмодзи слева и
жирный кликабельный ник. Без своего эмодзи стоит 👑. Ещё VIP получает особое приветствие при входе, итоги
без лимита, и бот общается с ним с шутливым уважением. Премиум-эмодзи видны, если у владельца бота есть
Telegram Premium, иначе вместо него показывается обычный эмодзи.

Боту в чате нужны права админа: ограничивать участников (мут), закреплять (закреп), назначать админов
(должность). Без нужного права товар не купить, Telegram сразу покажет причину.

Цены, включение, платежи и возвраты: `/admin` → ⭐ Монетизация. Магазин в конкретном чате выключается:
Чаты → чат → Фишки. Звёзды выводятся через Fragment.

## White label: копии бота для клиентов

Каждый клиент: отдельная копия на этом же сервере со своим ботом, ключом нейросети, базой и админкой.
Лимит памяти на копию 180 МБ.

```bash
bash /opt/linkhub/deploy/client.sh add vasya     # спросит токен бота клиента, его ID, ключ нейросети, дни и лимит чатов
bash /opt/linkhub/deploy/client.sh list          # кто работает
bash /opt/linkhub/deploy/client.sh logs vasya
bash /opt/linkhub/deploy/client.sh remove vasya
```

Дальше всё из бота: `/admin` → 💼 Клиенты. Там видно, жива ли копия, до какого числа оплачено, сколько чатов
и расход ИИ; кнопки **+30 дней, +7 дней, лимит чатов, пауза**. Не оплачено или пауза: копия молчит в чатах и
напоминает клиенту. За 3 дня до конца оплаты напоминание приходит и клиенту, и тебе.

## Установка у клиента через Docker Compose

Для продажи «своего бота»: клиенту отдаётся этот код, бот ставится на его сервер одной командой.

```bash
# на сервере клиента (нужны git и Docker)
git clone <репозиторий> chatbot && cd chatbot
cp .env.example .env
nano .env                      # BOT_TOKEN, OWNER_IDS (ID клиента), AI_API_KEY (его ключ нейросети)
mkdir -p data && sudo chown 10001 data
docker compose up -d --build
docker compose logs -f         # логи
```

Обновить: `git pull && docker compose up -d --build`. База лежит в папке `data/` рядом и не теряется.
Бэкап: скопировать `data/bot.db`.

## Сервер с 2 ГБ памяти

Установка сама создаёт swap на 5 ГБ. Отдельно: `bash /opt/linkhub/deploy/swap.sh 5`. Проверить: `free -h`.

## Установка на сервер (Ubuntu 24.04, systemd)

1. В @BotFather: создай бота, затем **Bot Settings → Group Privacy → Turn off**. Без этого бот не видит
   обычные сообщения в группах.
2. Заведи ключ API нейросети и пополни баланс на $5.
3. На сервере от root:

```bash
apt update && apt install -y git
git clone https://github.com/dalmatinec/linkhub /opt/linkhub
bash /opt/linkhub/deploy/install.sh
```

Скрипт спросит токен, твой Telegram ID и ключ нейросети, поставит всё и запустит бота как сервис.

4. Напиши боту в личку /admin, добавь его в группу, в /admin → Чаты задай имя, характер и тему чата.

### Управление

```bash
journalctl -u linkhub -f          # логи
systemctl restart linkhub         # перезапуск
nano /opt/linkhub/.env            # настройки (лимит трат, модель), потом перезапуск
bash /opt/linkhub/deploy/update.sh  # обновиться с GitHub
```

База лежит в `/opt/linkhub/data/bot.db`. Чтобы сделать бэкап, достаточно скопировать этот файл.

## Другая нейросеть

Подходит любой сервис с API как у OpenAI. В `.env` меняются три строки, например OpenRouter:

```
AI_BASE_URL=https://openrouter.ai/api/v1
AI_API_KEY=sk-or-...
AI_MODEL=имя/модели
```

Не забудь поправить `PRICE_IN` и `PRICE_OUT` под цены модели, иначе расход посчитается неверно.
